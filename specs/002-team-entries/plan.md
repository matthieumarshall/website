# Implementation Plan: Team Entries

**Branch**: `ea_api_start` | **Date**: 2026-06-07 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/002-team-entries/spec.md`

---

## Summary

Enable team managers from OXL member clubs to enter their EA-licensed athletes into a season, pay via Stripe (card + BACS Direct Debit), and receive PDF receipts. Admins can manage pricing and view all entries. Athletes are fetched from the England Athletics TRAPI API using the league's API credential and a client certificate. Entry fees are pro-rated per a fixed lookup table (price by fixtures remaining at time of entry), with separate junior (U9–U17) and adult (U20+) pricing.

---

## Technical Context

**Language/Version**: Python 3.11+
**Primary Dependencies**: FastAPI, HTMX, Jinja2, DuckDB, `stripe` (PyPI), `weasyprint` (PDF), `httpx` (EA API client with mTLS), Pydantic
**Storage**: DuckDB persistent (`data/app.duckdb`) — new tables via numbered SQL migrations
**Testing**: pytest + Playwright; EA API and Stripe mocked in unit tests; full journey in UI tests
**Target Platform**: Ubuntu VPS (Linux) behind nginx + uvicorn
**Project Type**: Web service (server-rendered, HTMX islands)
**Performance Goals**: EA API fetch < 5s (cached per session); Stripe redirect < 1s; PDF generation < 3s
**Constraints**: BACS settlement is asynchronous (T+3–7 days); EA API requires mutual TLS (PFX certificate); GBP-only payments
**Scale/Scope**: ~27 clubs, 5–20 athletes per club per season, ~5 batches per club per season; low traffic

## Complexity Tracking

No constitution violations. The feature is self-contained and follows existing patterns. The only new external integrations are:
- **EA TRAPI API** (mTLS, JSON REST) — handled in `entries.py` using `httpx.Client` with cert loaded from env-configured path.
- **Stripe** (webhook, Checkout Session) — handled in `payments.py`; webhook endpoint exempt from CSRF (uses Stripe signature instead).
- **WeasyPrint** (PDF) — no new complexity beyond system-level package install on VPS.
